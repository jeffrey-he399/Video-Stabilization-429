# Video Stabilization — ENSC 429 Group 10

This project implements a video stabilization system in MATLAB. The goal is to remove unwanted camera shake from handheld video recordings, producing a smooth output sequence. The system is designed to be efficient enough to approach real-time stabilization performance.
